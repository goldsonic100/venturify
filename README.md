# Venturify

**Learn from what didn't work.**

Venturify is a prototype for a curated startup post-mortem library: founder stories, lessons learned, and carefully contextualized financial information to help entrepreneurs make better decisions.

## Prototype features

- Responsive landing page and case-study library
- Search by company, sector, and lesson type
- Case-study detail modals
- A local-only submission draft form with copy-to-clipboard preview
- Privacy, evidence-labeling, and permission principles
- No external dependencies or build step

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to finish; GitHub will show the public site URL in the Pages settings.

## Important prototype limitations

- Case studies and numbers on the site are **fictional examples**, not real startup reports or verified financial disclosures.
- The submission form does not send, upload, or persist data. It only generates a local preview in the browser.
- No database, authentication, secure file upload, moderation dashboard, or deletion workflow is connected.
- Do not enter confidential information or upload sensitive documents into this prototype.
- Before accepting real founder stories, add secure storage, consent and permissions checks, moderation, privacy/deletion procedures, and a process to label self-reported versus independently verified claims.

## Suggested next steps

1. Decide on a backend and database for reviewed submissions.
2. Add admin moderation and abuse reporting.
3. Add clear contributor consent and data deletion workflows.
4. Only publish pitch decks and financial materials with explicit permission.
5. Add a verified/unverified evidence label to every real case study.
