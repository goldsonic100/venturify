Security boundaries

✓ Moderator RPCs check the private moderator allowlist.

✓ Account directory returns profile-level fields only.

✓ No service-role key is shipped to this browser page.

✓ Private messages and authentication credentials are not shown in this dashboard.

Account suspension, deletion, and authentication-provider actions are not enabled here yet; those need a separate audited server-side workflow.
